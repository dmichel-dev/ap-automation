What happens to each invoice

  1. 1

    Received

    From this page or by email, picked up by an n8n workflow.

  2. 2

    Read

    Mistral OCR turns it into structured data, in any language or script.

  3. 3

    Checked

    By deterministic code, never by the AI: the document can't talk its way through.

  4. 4

    Routed

    Ready to post Needs review Rejected
